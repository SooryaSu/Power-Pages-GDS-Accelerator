Low-Code GDS Accelerator

Utilise this tool to efficiently develop a Power Pages project that adheres to the government digital services standard. The Low-Code GDS Accelerator is designed to streamline your development process by giving you a basic template to start your project.

GitHub

Documentation for this project can be found on the GitHub repository page. Here, you will find detailed instructions, examples, and support to help you make the most of the Low-Code GDS Accelerator.

Getting Started

  1. ​​Install the Tool: Follow the GithHub instructions to set up the website in your chosen environment.
  2. ​​Develop Your Project: Use the drag-and-drop interface to build your Power Page project quickly and efficiently.
  3. ​​Styling Your Project: Styling will need to be applied by editing the HTML. Refer to the GOV.UK design system for documentation.
