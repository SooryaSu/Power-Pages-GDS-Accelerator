Low-Code GDS Accelerator

Utilise this tool to efficiently develop a Power Page project that adheres to the Government Digital Service Standard. The Low-Code GDS Accelerator is designed to streamline your development process.

GitHub

Documentation for this project can be found on the GitHub repository page. Here, you will find detailed instructions, examples, and support to help you make the most of the Low-Code GDS Accelerator.

Getting Started

  1. Install the Tool: Follow the installation guide to set up the Low-Code GDS Accelerator in your development environment.
  2. ​​Develop Your Project: Use the drag-and-drop interface to build your Power Page project quickly and efficiently.
  3. ​​Test and Deploy: Utilize built-in testing tools to ensure your project is ready for deployment.
