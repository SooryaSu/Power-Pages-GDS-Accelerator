Form Styling

During development, you'll likely add forms to capture information. 

Initially, the styling of these forms might not appear as expected, particularly for elements like radio buttons. However, when you preview the form, you'll see the correct styling. This discrepancy occurs because the JavaScript responsible for applying certain styling does not run within the editor.
